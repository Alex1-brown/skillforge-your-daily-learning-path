# SkillForge MVP

## Build
- Create a polished Graphite + Lime design system using Space Grotesk and Manrope.
- Add a public landing page and an app shell with desktop sidebar and mobile bottom navigation.
- Build Dashboard, Skills, Daily Task, Progress, and Profile routes with distinct page metadata.
- Use shared local demo data and browser-only persisted interactions for task completion and skill selection.
- Add responsive layouts, accessible controls, progress visualizations, and restrained motion.

## Technical details
- Keep all data local and organize it behind typed modules so authentication and Cloud storage can replace it later.
- Use TanStack Router links and separate route files for every primary page.
- Validate the running preview at desktop and mobile widths after implementation.
