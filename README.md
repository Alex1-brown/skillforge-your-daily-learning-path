# SkillForge: Your Daily Learning Path

Создай реальный продаваемый MVP без Replit: современное веб-приложение под названием SkillForge. Идея: пользователь выбирает навык (English, Python, AI, Programming), получает короткий ежедневный план на 10–20 минут, отмечает выполнение и видит прогресс. Сделай очень качественный мобильный-first интерфейс, тёмную тему, красивую dashboard-страницу, карточки навыков, streak/progress, страницу задачи дня и страницу профиля. Пока без внешнего API и без платных сервисов. Используй локальные демо-данные. Добавь понятный landing page с CTA “Start learning”. Приложение должно выглядеть как настоящий SaaS-продукт, а не учебный шаблон. Сделай responsive UI и подготовь структуру так, чтобы позже можно было подключить авторизацию и базу данных.
